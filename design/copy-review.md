# PayGuard copy review (senior UX writer pass)

Base: Nazar's version. Source: the rendered text of 34 screens and states, plus toasts, reminder messages and receipts.
Status: **for approval. Nothing in the product has been changed.**
Rows tagged **[with flow]** depend on the unlock model (preview, approve, pay, unlock). I've given a "now" line that is accurate for today's pay-first flow, and the final line is noted so you can see where it is heading.

## 1. Voice rules
1. Say what happened, then what to do. Status first, verb on the button.
2. Short: a status is 6 words or fewer; a hint is one sentence.
3. One word per idea (glossary below). No synonyms for variety.
4. Sentence case everywhere. No exclamation marks. No jargon.
5. Calm about lateness: "3 days late", never "overdue" or "you must".
6. Never claim PayGuard holds, guarantees or protects money. Describe what happens ("Approving sends ₹60,000 to Meera").
7. Names only where they help: button labels ("Remind Sana") and the client's own pages. Everywhere else, the product speaks neutrally.
8. Dates as "Tue 20 Oct" (no comma). Amounts as "₹35,000". Relative time when under a week ("in 2 days"), a date after.
9. Errors say what to fix, not what went wrong.

## 2. Glossary
| Use | Instead of |
|---|---|
| **Stage** | milestone, phase |
| **Pay / paid** | fund, funded, secured |
| **Preview** (watermarked copy) | protected preview, proof |
| **Original files** | source, raw, final files |
| **Approve** | release, sign off |
| **Report a problem** | raise an issue, dispute |
| **Paused** | on hold |
| **Late** (3 days late) | overdue |
| **Reply** | respond |
| **Link** (to the client) | invite |
| **What's included** | scope |
| **Rounds of changes** | revisions |
| **Approved automatically** | auto-approved |
| **PayGuard fee** | service fee, fee share |

Status words (client and freelancer see the same ones): **Not paid · Paid · In review · Changes requested · Approved · Paused · Refunded.** (After the flow change: Not started → In progress → In review → Changes requested → Awaiting payment → Unlocked.)
