# PayGuard accessibility and low-end review (slug: a11y)

Method: code reading plus headless-Chrome audits I ran (computed contrast on 32 screens in light and dark, target sizes, focus-ring clipping, 320px reflow). "(code)" marks inference from source, not observation.

## 1. Verdict
The visual layer is accessible by instinct (real focus ring, text on every status, reduced-motion handled, plain copy, passing dark tokens). The engineering underneath is not: every action rebuilds the DOM so focus is lost, dialogs are unmanaged, many clickables are not controls, and the 683 KB file is 80% mascot sprite. The money-release path is hard without a mouse and heavy on a bad network.

Scores (/10): perceivable/contrast 5 | operable (keyboard, focus, targets) 3 | understandable (forms, errors, copy) 6 | robust (markup, ARIA) 3 | motion 7 | colour-independence 7 | mobile and low-end 4.

## 2. What is working: keep it
- Status is never colour-only: each badge, `.sev` dot and `.dot` sits beside text ("Not funded · 3 days overdue"). Soft-orange "Overdue" is fine because the word is there.
- Global `:focus-visible` ring (#2F5BEA, 5.5:1 on white; #7C9BFF in dark), `aria-pressed` filter chips, `aria-expanded` on "Waiting on clients", `inert` on filtered rows, `aria-label` on icon buttons, `role="alert"` on card decline.
- Thorough `prefers-reduced-motion` block plus JS `REDUCE`; only one mascot animates per screen.
- Dark token pairs all pass (muted-fg 6.9-7.8:1, badges 6.0-9.5:1). Zoom allowed. 320px reflow clean on 7 of 8 screens.
- "You have not been charged" and the plain-words terms are good cognitive design.

## 3. Findings

**F1. S1 | all dialogs and views | DOM rebuilt on every action; modals unmanaged.** `render()` sets `app.innerHTML` each click. Measured: after opening Approve, Documents and Released dialogs `activeElement` is `body`. Dialog has `role="dialog" aria-modal` but no name, no focus move (only the changes dialog focuses its textarea), no trap, no return, background not inert. Receipt-dialog tabs re-render and drop focus. `<title>` stays "PayGuard", no history entries, so Android Back exits the app. *Why:* keyboard and screen-reader users cannot reliably reach "Approve and release ₹60,000". WCAG 2.4.3, 4.1.2, 2.4.2, 4.1.3. *Fix:* focus the dialog h2, `inert` the rest, restore to opener, `aria-labelledby`; keep focus across render by `data-key`; per-view title and h1 focus; hash routes. *Effort:* M.

**F2. S2 | today-active, project-*, client-review | Clickables that are not controls.** `li[data-a=selms]` (every milestone row, both roles), `li.att`, `.easy`, `.ag li`, `.bigcal .chip` have no tabindex or role. On Today, fund, approve and invite rows expose only "Remind/Nudge/Resend", so a keyboard user cannot open that project from Today (audit confirms). WCAG 2.1.1, 4.1.2. *Fix:* client name becomes an `<a href>` with stretched `::after`; drop row handlers. *Effort:* S-M.

**F3. S2 | clients, plan, project-*, client-changes-dialog | Focus indicator invisible or clipped (measured, screenshot-verified).** Clients `.fr` rows: 2px ring fully clipped by `.fclip{overflow:hidden}`. Swatches: `.sw{outline:1px #E4E4E7}` overrides the global ring (1.27:1). `.tabs` and `.fb-bar` buttons clip top and bottom. Tone, Grammar and Send are tabbable while zero-width (three phantom stops). WCAG 2.4.7. *Fix:* `outline-offset:-2px` in clipped containers; `.sw:focus-visible{box-shadow:0 0 0 2px var(--bg),0 0 0 4px var(--ring)}`; `inert` collapsed bar parts. *Effort:* S.

**F4. S2 | badges, rows, calendar, avatars | Text contrast.** `--muted-fg #71717A` is 4.83:1 on white but **4.40:1 on `--muted #F4F4F5`** and 4.44-4.49 on calendar tints. Hits the "Not funded" badge (41 instances), selected/hovered milestone `.sub`, unselected tabs, weekday headers, 10.5px `.fcount`. Client-colour initials on 16% tint: amber LR 1.92, teal TH 2.82, orange NC 3.03, pink BS 3.66. Out-of-month days 1.7-1.8. WCAG 1.4.3. *Fix:* `--muted-fg:#6B6B74` (4.8 on muted); initials in `color-mix(var(--c) 55%, #000)`. *Effort:* S.

**F5. S2 | every form | Non-text contrast.** `.input` border #E4E4E7 on white is 1.27:1, so fields vanish in sunlight on cheap panels; selected tab (white on #F4F4F5) is 1.1:1. WCAG 1.4.11. *Fix:* input and select border #8A8A93 (3.4:1). *Effort:* S.

**F6. S2 | m-payments, m-clients | Phone tables hide the answer.** At 390px "You receive" is clipped and **Status and Documents are off-screen**; `scrollbar-width:none` removes the cue; chips clip ("Awaiti"). Payments exists to answer "where is my money". WCAG 1.4.10, 1.3.1. *Fix:* below 640px render cards (client, milestone, amount, badge). *Effort:* M.

**F7. S2 | whole file | Document foundation.** No `<!doctype>` (measured `compatMode: BackCompat`), no `<html lang>`, no `<main>`/`<header>`; sidebar is an `<aside>` of buttons, current page is a `.on` class with no `aria-current`; no skip link; Today goes h1 to h3; h1 swallows its Edit button ("Bloom Studio Edit"). WCAG 3.1.1, 1.3.1, 2.4.1. *Fix:* doctype and `lang="en"` in head.html, landmarks, `aria-current`. *Effort:* S.

**F8. S2 | project-*, client-review, clients | Misused ARIA.** `role=tablist/tab` in three places lacks tabpanel, `aria-controls`, roving tabindex and arrow keys. The `role=table` divs have an empty column header and a non-row `.f-empty`; filtering announces nothing. WCAG 4.1.2, 1.3.1, 4.1.3. *Fix:* page tabs become links with `aria-current`; file switcher uses `aria-pressed`; native `<table>`; `role=status` "4 of 8 clients". *Effort:* M.

**F9. S2 | plan-err, client-decline, setup | Forms and recovery.** Errors are `.hint-err` spans without `aria-invalid`/`aria-describedby`; after a failed submit focus is lost and the toast says "Check the highlighted fields" for 4.2s. No required markers; no `autocomplete` (`cc-number`, `cc-exp`, `cc-csc`, email, name). Decline re-render resets the card number to the default, wiping typed values (prototype artefact; must not ship). Disabled "Continue" gives no reason. WCAG 3.3.1, 3.3.3, 1.3.5, 3.3.7. *Fix:* focusable error summary linking to fields; `aria-disabled` plus hint. *Effort:* M.

**F10. S3 | calendar, m-calendar | Calendar and per-client colour.** Mini-calendar days are plain divs; events are a colour dot plus `title` only (no touch, keyboard or SR). At ≤900px big-calendar chips shrink to 6px dots (`font-size:0`) that remain click targets: colour-only identity, no text. Palette has confusable trios (teal #0F9D8A / #0B7285 / green #2B8A3E) and amber at 2.17:1. Lists are fine since org names accompany colour. WCAG 1.4.1, 1.3.1, 2.5.8. *Fix:* agenda list on phones; desktop day cells as buttons "14 Oct: 2 events"; 8 colours varied in lightness. *Effort:* M.

**F11. S3 | today, clients, m-* | Targets and text.** "Remind Sana", "Open", "Upload" 30px; chips 28; month arrows 28; tabs 29; `.chipb` 26; breadcrumb link 21 (<24); checkbox 16. Row click abuts a 30px button, so a mis-tap sends a reminder with no undo. Info lines are 12px muted; chips 11px. Key text is ellipsised without tooltips; fixed heights (`.btn` 36, `.badge` 20) clip under text-spacing. WCAG 2.5.8, 1.4.12. *Fix:* `@media (pointer:coarse)` 44px, 14px floor, `min-height`, undo for Remind. *Effort:* S.

**F12. S3 | client-changes-dialog | AI tidy-up bar.** `.fb-pass[aria-live=polite]` is rewritten every 26ms, so screen readers stutter; "Improving…" is silent; swapping `cont.innerHTML` destroys the focused button and Keep/Discard get no focus. WCAG 4.1.3, 2.4.3. *Fix:* show result at once, announce "Suggestion ready" via a hidden status, focus Keep. *Effort:* S.

**F13. S3 | all toasts, reply-by | Timing and consequence.** Toasts vanish at 4.2s with no pause or dismiss, yet hold the only confirmation ("Round 1 of 2 used", "Reminder sent", copied link). "The reply date has passed. Take a look when you can." never says what happens next. WCAG 2.2.1, 3.3.2. *Fix:* 8s minimum, pause on hover/focus, mirror result in the page, state the lapsed-date consequence. *Effort:* S.

**F14. S3 | client-review | Reviewing the work.** Preview alt is the filename ("Moodboard.svg"); fixed 16:10 stage, context menu blocked, no zoom; watermark at 1.56:1 across the artwork. Low-vision or SR clients cannot judge what they pay ₹60,000 for. WCAG 1.1.1, 1.4.4. *Fix:* optional "describe this delivery" field, "Open full size" with pinch zoom. *Effort:* M.

**F15. S2 | whole product | Weight and low-end Android.** Measured: 683 KB raw, **238 KB gzip**; mascot sprite is 504 KB raw (191 KB gzip), 33 traced symbols, 14,237 path commands, yet a screen uses 1-3 poses. `#app` is empty until the whole file parses; Google Fonts CSS is render-blocking. 22 `color-mix()` calls (Chrome 111+) without fallback: on older WebViews sticky `.topbar` turns transparent and `.drop`/`.centerpage` lose fills; `inert` needs 102+. Three `backdrop-filter` blurs are costly on cheap GPUs. List stagger holds items at opacity 0 up to ~0.85s (m-today shot caught mid-fade). A guest opening the WhatsApp link on 3G waits for all of it. *Fix:* lazy-load poses, self-host a Latin Geist subset, solid fallbacks before `color-mix`, drop blurs, skeleton shell, under 100 KB gzip for the client link. *Effort:* M.

**F16. S4 | various | Polish.** Infinite `breathe`/`sway` loops and 6.5-11s expression flicks lack an in-app pause (WCAG 2.2.2; OS setting honoured, add a toggle for Android Go). Swatches read "Color 3": name them. `initials()` returns "·" for Devanagari or Tamil names (code). Forced-colors strips dots and progress bars. Guest jargon ("Fund the first milestone", "GST on service fee") needs a one-line gloss.

## 4. Rethink / bold bets
1. **Stop re-rendering the world.** Keyed patching plus a router fixes F1, F2, F7, F8 and gives Back and deep links.
2. **One phone-first row component** (name link, amount, badge, 44px action) for Today, Clients and Payments; calendar becomes an agenda on phones.
3. **Ship the mascot as data, not weight.** One hero pose inline, the rest lazy.

## 5. Top 5 fixes, in order
1. Modal and focus management; preserve focus across `render()` (F1).
2. Real links and buttons for rows; repair clipped and overridden focus rings (F2, F3).
3. Doctype, `lang`, landmarks, `aria-current`, per-view titles (F7).
4. Contrast: `--muted-fg` #6B6B74, input border #8A8A93, darker initials (F4, F5).
5. Cut first-load weight, add `color-mix` fallbacks, phone cards for tables (F15, F6).
